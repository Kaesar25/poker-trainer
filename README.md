# Poker Trainer

Entraîneur de poker personnel (PWA) : cash game et tournois contre des bots, mode Chip leader, coach en direct, historique et statistiques. Jetons fictifs uniquement.

- Code source : `src/`
- Site publié (GitHub Pages) : dossier `docs/` (généré par `npm run build`)

Développement : `npm install` puis `npm run dev`.
